# Contributing to sim-starterkit

We appreciate your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b my-change`)
3. Make your changes
4. Submit a pull request with a short description of what changed and why

## Guidelines

- Never commit secrets. Keep API keys in a local `.env` file, which is git-ignored.
- Keep pull requests focused on one change.

## Code of Conduct

Be respectful and constructive.

## Questions?

Open an issue for discussion.
